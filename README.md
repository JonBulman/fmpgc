## About The Project

[![Product Name Screen Shot][product-screenshot]](https://example.com)

Sending plain text emails programmatically can look unprofessional. This project provides a lightweight Python backend designed to parse and send beautiful HTML email templates. It is built to be easily integrated into existing Python applications, CRMs, or notification systems.

### Key Features
* **HTML Template Engine:** Cleanly separates your Python logic from your email design using responsive HTML templates.
* **SMTP Integration:** Easily connect to Gmail via environment variables.
* **Dynamic Content Injection:** Pass variables from Python directly into your HTML email body (e.g., usernames, reset links).
